---
description: 커밋규칙(docs/git-convention.md)에 맞는 커밋 생성
---

현재 변경사항을 팀 커밋규칙에 맞게 커밋해줘.

1. `git status`와 `git diff`로 변경 내용을 파악한다.
2. 변경이 여러 논리적 단위로 섞여 있으면 커밋을 나누자고 제안한다 — 하나의 커밋에는 하나의 논리적 변경만.
3. `docs/git-convention.md`를 읽고 그 형식으로 커밋 메시지를 작성한다.
4. `.env` 등 시크릿 파일이 스테이징에 포함되지 않았는지 확인한 후 커밋한다.
5. 현재 브랜치가 `dev`면 커밋 전에 `<type>/<domain>` 형식의 브랜치를 먼저 만들자고 제안한다.
